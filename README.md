# 快速排序交互式教学系统

🚀 一个可视化的快速排序算法教学网站，一步步演示排序过程。

## 功能特点

- 📊 **可视化演示**：数组方块实时显示，颜色区分不同状态
- 🎯 **指针跟踪**：实时显示 i、j 指针位置
- 💻 **代码高亮**：Python 代码实时高亮当前执行行
- 📈 **变量监控**：显示 pivot、i、j 的实时值
- 🎮 **交互控制**：上一步/下一步/自动播放/速度调节
- 📱 **响应式设计**：支持手机、平板、电脑访问

## 在线访问

👉 [点击访问](https://你的用户名.github.io/quick-sort-demo/)

直接双击 `index.html` 文件即可在浏览器中打开。

## 技术栈

- 纯 HTML + CSS + JavaScript
- 无需任何依赖
- 单文件应用

## 算法说明

快速排序核心思想：
1. 选基准（pivot）
2. 分区操作：双指针扫描，大的放右边，小的放左边
3. 递归调用：对左右分区重复以上步骤

时间复杂度：O(n log n)  
空间复杂度：O(log n)
