// Partition函数（一趟排序，返回枢轴位置） int Partition(SqList &L, int low, int high) { L.r[0] = L.r[low]; // 用子表的第一个记录作为枢轴记录 pivotkey = L.r[low].key; // 枢轴关键字 while (low < high) { // 从表的两端交替地向中间查找 // 从右向左找小于pivotkey的元素 while (low < high && L.r[high].key >= pivotkey) --high; L.r[low] = L.r[high]; // 将比枢轴小的移到低端 // 从左向右找大于pivotkey的元素 while (low < high && L.r[low].key <= pivotkey) ++low; L.r[high] = L.r[low]; // 将比枢轴大的移到高端 } L.r[low] = L.r[0]; // 枢轴记录到位 return low; // 返回枢轴位置 } // QuickSort函数（递归实现快速排序） void QuickSort(SqList &L, int low, int high) { if (low < high) { pivotloc = Partition(L, low, high); QuickSort(L, low, pivotloc - 1); QuickSort(L, pivotloc + 1, high); } }

快速排序相较于其他排序的优势

⏱️ 时间效率高

平均 O(n log n)，常数因子小，实际运行速度快。比 O(n²) 的冒泡、选择、插入排序快很多。

💾 原地排序

空间复杂度 O(log n)，只需递归栈空间。归并排序需要 O(n) 额外空间。

🔧 缓存友好

顺序访问模式，局部性好。堆排序虽然也是 O(n log n)，但缓存命中率低，实际更慢。

👑 实战之王

C/C++ 的 qsort、Java 的 Arrays.sort（基础类型）底层都是快排变种，工程上广泛使用。

排序算法 时间复杂度 空间复杂度 稳定性 实际速度
快速排序 O(n log n) O(log n) 不稳定 ⭐⭐⭐⭐⭐
归并排序 O(n log n) O(n) 稳定 ⭐⭐⭐⭐
堆排序 O(n log n) O(1) 不稳定 ⭐⭐⭐
冒泡/选择/插入 O(n²) O(1) 稳定 ⭐

缺点：最坏情况 O(n²)（数组已有序时），但随机选枢轴或三数取中可以规避。
